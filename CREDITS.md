# Credits and Asset Licences

**LAST MAGAZINE** is a first person survival horror shooter made in Godot 4.7 by Taha Keler.

## Engine

- [Godot Engine](https://godotengine.org/) 4.7.2, MIT Licence

## Made for this game

- The Amethyst Labyrinth map (`amethyst_labyrinth/`), built in Blender from Kenney's Modular Dungeon Kit, with help from ChatGPT (Astra 6)
- The zombie pack (`assets/models/zombies/`): the normal, heavy and runner zombies with their textures and animations, made in Blender from MakeHuman CC0 assets, with help from ChatGPT (Astra 6)
- All game code (`src/`), scenes, UI and HUD
- Gunshots, the Brute's growl, the Screamer, the cave drone and the tension pulse, generated by `tools/generate_audio.gd` (`assets/audio/generated/`)
- All lighting, materials and environment setup, and the project icon

- [Godot AI](https://github.com/hi-godot/godot-ai) (MCP add-on, MIT, `addons/godot_ai/`), used to build the headshot feature from the editor. It is editor-only; its runtime helper is removed from exported builds.

## AI assistance

The game code and scenes were made with Claude Code as an AI assistant (the headshot feature through the godot-ai MCP). The Blender assets were made with help from ChatGPT (Astra 6).
